# 🐍 Python Mini Toolkit

A beginner-friendly, menu-based Python application featuring 5 interactive mini tools.  
Built as a completion showcase project to demonstrate Python fundamentals learned during the course.

---

# ✨ Features

| # | Tool | Description |
|---|---|---|
| 1 | Grade Calculator | Enter multiple marks and calculate the average with a letter grade |
| 2 | Even or Odd Checker | Check whether a number is even or odd and test divisibility |
| 3 | Number Guessing Game | Guess a secret number between 1–100 in up to 10 tries |
| 4 | To-Do List Manager | Add, view, and remove tasks from a personal to-do list |
| 5 | Daily Motivation Generator | Display a random motivational quote |

---

# 🧠 Python Concepts Used

- Variables & Data Types — strings, integers, booleans, lists
- User Input & Output — `input()`, `print()`, f-strings
- Type Casting — `int()`, `.strip()`, `.lower()`
- Arithmetic Operators — `+`, `-`, `*`, `/`
- Modulus Operator — `%` for even/odd and divisibility
- Comparison Operators — `==`, `!=`, `<`, `>`, `<=`, `>=`
- Logical Operators — `and`, `or`, `not`
- Conditionals — `if`, `elif`, `else`
- Loops — `while`, `for`, `range()`, `break`, `continue`
- Functions — parameters, arguments, return values
- Lists — `append()`, `pop()`, `len()`, `enumerate()`
- Modules — custom module (`helpers.py`) and built-in modules (`random`)

# ▶️ How to Run the Project

1. Make sure Python 3 is installed on your computer.
2. Clone or download this repository.
3. Open your terminal and navigate to the project folder:

```bash
cd python-mini-toolkit
```

4. Run the program:

```bash
python main.py
```

5. Follow the on-screen menu to explore each tool.
